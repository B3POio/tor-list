# Tor Onion Directory

A curated collection of Tor onion services providing access to privacy tools, independent journalism, secure communication, and online resources.

These services are accessible through the [Tor Browser](https://www.torproject.org/). Onion addresses provide access to websites through the Tor network, helping protect user privacy and resist censorship.

## Accessing Onion Services

1. Download and install the official [Tor Browser](https://www.torproject.org/download/).
2. Connect to the Tor network.
3. Open any of the onion links listed above.

**Security Note:** Onion services may change addresses, become unavailable, or be impersonated. Always verify addresses against official sources before sharing sensitive information. Inclusion in this directory does not constitute a security endorsement.

For confidential submissions, consult the [official SecureDrop directory](https://securedrop.org/directory/) and follow the receiving organization's security guidance.
