# Tor Onion Directory

A curated collection of Tor onion services and useful resources focused on privacy, secure communication, independent journalism, digital rights, and open information.

Onion services are accessible through the [Tor Browser](https://www.torproject.org/). They provide access to websites through the Tor network, helping protect user privacy and resist censorship.

Addresses should be verified against official sources before use. Onion services may change addresses or become unavailable.

## Accessing Onion Services

1. Download and install the official [Tor Browser](https://www.torproject.org/download/).
2. Connect to the Tor network.
3. Open an onion link in Tor Browser. For submission portals listed as plain text, copy the address into the browser's address bar.

**Security Note:** Onion services may change addresses, become unavailable or be impersonated. Always verify addresses against official sources before sharing sensitive information or submitting confidential material. Inclusion in this directory does not constitute a security endorsement.

For additional verification, consult the [Tor Project's official onion services directory](https://onion.torproject.org/) and the [official SecureDrop directory](https://securedrop.org/directory/).
